# AEN: Agripreneurs Empowerment Network

An agricultural marketplace for Zimbabwe, built as an offline-first progressive web app. Farmers list produce, buyers find it, and admins manage the network from a dashboard.

**Live site:** https://aen-zw.vercel.app

## What it does

- Farmer listings and a marketplace, built to work on patchy rural connections
- An admin dashboard for managing listings and members
- A price index drawn with Recharts
- Live weather from Open-Meteo, based on each farm's province
- Installable, offline-first PWA
- Alt text on every one of its 60+ images

## Stack

React · Vite · Tailwind CSS · Firebase (Firestore, Auth) · Recharts · vite-plugin-pwa · Framer Motion

## My role

I designed and built the responsive, offline-first UI and the Firebase data layer, and deployed it on Vercel.

This is a public snapshot of a private repository, shared for portfolio review. Credentials and seed data have been removed. Copy `.env.example` to `.env` and add your own Firebase project values to run it.
